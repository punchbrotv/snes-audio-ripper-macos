# SNES Audio Ripper for macOS — v1.0.0-mac.1

The first Apple Silicon macOS release of Samsqwamch's SNES Audio Ripper, ported by PunchBro with Codex by OpenAI.

Download **SNES-Audio-Ripper-macOS-arm64.zip**, unzip it, and move the app to Applications. Requires macOS 13+ on Apple Silicon. The app includes its runtime, native emulator core, and audio dependencies.

- Native macOS file dialogs, ⌘O, and output-folder selection.
- ROM, single-ROM ZIP, and split-file input.
- Background extraction, cancellation, and the original built-in music player.
- Full application source checked into the repository; building no longer retrieves the Windows installer.
- A wildly photo-heavy README, approachable architecture diagram, and public-domain SNES hardware gallery.

The app is ad-hoc signed, not Apple-notarized. If macOS blocks opening it, use System Settings → Privacy & Security → Open Anyway after attempting to launch it, if you trust this release. `SHA256SUMS.txt` provides asset checksums.
