# Descriptive instrument tracks

Logic exports can now name instruments from local sample-fingerprint profiles. Track and region labels put the instrument first, retain compact voice/sample references, and distinguish separate envelope or tuning variants. An exact PCM-and-loop match prevents a reused sample slot from inheriting the wrong name.

Every project includes an Instrument Guide with naming sources, loops, sample duration, captured envelope registers, and note counts. Unknown sounds remain explicitly unidentified; DSP-noise tracks are labeled Noise. No game-specific names, profiles, ROMs, or samples are bundled. See [instrument-name profiles](https://github.com/punchbrotv/snes-audio-ripper-macos/blob/main/docs/track-names.md#instrument-names).

Naming does not change the performance, samples, Sampler routing, or source-beat alignment.

Verified with 30 passing tests and a packaged export of 40 music tracks plus 92 effects. All 31,295 notes and the complete MIDI event records are byte-identical to the preceding aligned export; every sample WAV is byte-identical. Descriptive names were written into 453 instrument tracks, with explicit fallback labels for unmatched sounds.

Original Windows application: **Samsqwamch**. macOS port published by **PunchBro**, built with **Codex by OpenAI**. Native Logic writing uses **Jon Kubis's LogicProFormatWriter**.

Apple Silicon; macOS 13+. Ad-hoc signed, not notarized.
