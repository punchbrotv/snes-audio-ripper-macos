# Readable soundtrack filenames

Import a local track-name profile using **File → Import Track Names…**. Future Logic, MIDI, WAV, and MP3 exports append verified titles to their stable track numbers, such as `Music Track-15 - Mountain Path.logicx`.

- Profiles match the exact ROM fingerprint and discovery command, so names cannot silently spill over to another ROM revision.
- Adjacent `.tracks.json` profiles are also supported. Unnamed tracks retain their existing filenames; duplicate titles retain distinct track IDs.
- Manifests include the ROM fingerprint and full titles. MIDI metadata and Logic export metadata also receive the titles.
- Profiles are optional local data. The application remains game-independent and does not bundle a soundtrack-title database, ROMs, or extracted samples.

See [the profile guide](https://github.com/punchbrotv/snes-audio-ripper-macos/blob/main/docs/track-names.md) for the format and import instructions. Existing exports are left intact.

Verified with 21 automated tests and a full packaged Logic export: 40 music tracks, 92 effects, zero export failures, and all 40 music titles matched.
