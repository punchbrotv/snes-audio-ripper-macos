# The extremely unnecessary SNES hardware gallery

**48 source photographs. Eight contact sheets. An unreasonable amount of gray plastic.**

Every hardware photograph is by Evan-Amos / Vanamo Media and is public domain. [Full source register and editing notes](assets/SOURCES.md). These are independent hardware photos, not official advertisements.
