# Source beats instead of late sound-chip writes

A correct BPM alone could still leave exported notes slightly after Logic's grid lines: the exporter retained sound-chip command execution times rather than the sound program's musical tick positions.

Timing profiles now support verified `beatAnchors`, mapping captured seconds to original sequencer beats. Logic and MIDI can put note attacks exactly on their source positions, including triplets and fractional-beat echoes. Releases and bends use the same map. This score-aligned mode removes execution delays and can slightly tighten playback; ordinary tempo profiles continue to preserve elapsed-time performance. WAV/MP3 are unchanged.

The data remains optional, local, and matched to the exact ROM. No game-specific addresses, titles, profiles, ROMs, or samples are bundled. See [the timing guide](https://github.com/punchbrotv/snes-audio-ripper-macos/blob/main/docs/track-names.md#exact-source-beats).

Verified with 27 automated tests and a full packaged export: 40 music tracks, 92 effects, zero failures. Checked 30,378 native note events against the conversion and independently traced sequencer positions; all 126 notes in the reported bass part land exactly on eighth-note boundaries. Sample bytes are unchanged.

Original Windows application: **Samsqwamch**. macOS port published by **PunchBro**, built with **Codex by OpenAI**. Native Logic writing uses **Jon Kubis’s LogicProFormatWriter**.

Apple Silicon; macOS 13+. Ad-hoc signed, not notarized.
