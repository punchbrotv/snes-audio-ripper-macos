# Beat grids that follow the performance

Logic and MIDI previously used a fixed 120 BPM reference: playback timing was correct, but bars and beats did not describe the music.

This update supports local timing profiles with tempo changes, meter, and the first-beat position. Note starts, releases, and pitch bends are converted together, preserving performance timing. Without a profile, music exports attempt a steady-pulse estimate; inconclusive results retain an explicitly unresolved reference grid. Estimates do not guarantee the intended meter or half/double-time interpretation.

See [musical timing profiles](https://github.com/punchbrotv/snes-audio-ripper-macos/blob/main/docs/track-names.md#musical-timing). Timing data remains local and ROM-matched; no game-specific data or extracted samples are bundled.

Verified with 25 automated tests and a full 40-music/92-effect packaged export. Compared 232,695 native note/controller events against the prior export: maximum playback-time difference was 1.16 ms after the specified startup-silence trim. Original sample bytes matched exactly.

Original Windows application: **Samsqwamch**. macOS port published by **PunchBro**, built with **Codex by OpenAI**. Native Logic writing uses **Jon Kubis’s LogicProFormatWriter**.

Apple Silicon; macOS 13+. Ad-hoc signed, not notarized.
