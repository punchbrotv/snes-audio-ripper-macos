# Logic Pro export with original SNES instruments

Choose **Logic Pro · original samples** to export each discovered sound as a native `.logicx` project. Open it in Logic and press Space: editable notes and the original samples are already mapped to the built-in Sampler. Samples are included inside the project package.

- Keeps the shared track catalog and stable numbering across MP3, WAV, MIDI, and Logic.
- Preserves sample loops, timing, relative pitch, pan, and pitch bends. Voice/instrument combinations use separate tracks.
- Includes the project writer runtime. No Python installation, source download, additional plug-in, or manual instrument assignment is needed.
- Sampler envelopes and console echo/noise/pitch modulation remain approximations; WAV and MP3 retain the emulated console performance. Wide pitch sweeps can retrigger adjoining notes.

Checked with 18 automated tests, complete 40-music/92-effect fixture exports, and native Logic playback/bounce tests of embedded samples and pitch bends. Moving a project was also checked.

Original Windows application: **Samsqwamch**. macOS port published by **PunchBro**, built with **Codex by OpenAI**. Native Logic project writing uses **Jon Kubis’s MIT-licensed LogicProFormatWriter**.
